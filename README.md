# Database Kidung

### About The Project

Kidung yang banyak dan aplikasi yang outdated menyebabkan banyak pengguna mengalami kesulitan oleh karena itu project ini dibuat agar dapat membantu projek lainnya yang berkaitan dengan kidung.

### Usage
1. Pertama configurasi database yang ingin digunakan :
`$database_to_convert = new Database($dsn, $username, $password)`
2. Modifikasi nama tabel & kolomnya (optional).
3. Jalankan :
`php processing/index.php`
